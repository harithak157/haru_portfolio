Loanword Tracing

A Computational Linguistics and Explainable Machine Learning Platform. Exploring the historical migration of words across languages through character-level linguistic analysis, machine learning, and explainable AI.

Computational Linguistics Machine Learning Explainable AI Python React

Motivation & Existing Gap

Motivation

Languages continuously evolve through cultural contact, trade, migration, and communication. During these interactions, words travel from one language to another, adapting their spelling and pronunciation along the way.

This project aims to computationally investigate lexical borrowing by identifying probable donor languages, analyzing character-level linguistic patterns, and tracing historically documented word migration pathways across multiple languages.

Existing Gap

Traditional etymology resources such as Wiktionary and Etymonline primarily provide dictionary-based historical information for previously documented words.

Existing digital resources have limited predictive capabilities for uncatalogued words and do not provide character-level quantitative explanations of linguistic similarities.

This motivated the development of a system that combines machine learning-based donor language prediction, character-level explainability, and historically documented etymological evidence to explore how words migrate between languages.

NLP Pipeline

01

Raw Dataset

Collect and organize annotated loanword records containing words, meanings, donor languages, recipient languages, and historical references.

02

Text Preprocessing and Normalization

Normalize input text using Unicode NFC normalization to ensure consistent representation of words across different scripts.

03

Script Detection and Transliteration

Identify the writing system of the input word using Unicode character ranges. Use normalized phonetic transliterations for cross-language character analysis.

04

Character N-Gram Feature Extraction

Extract overlapping character n-grams of lengths 1–4 and convert them into numerical representations using TF-IDF vectorization.

05

Machine Learning Classification

Train a balanced multiclass Logistic Regression classifier to predict the probable donor language. Compare its performance with Complement Naive Bayes as a baseline model.

06

Character-Level Explainability

Analyze the contribution of individual character sequences to the predicted language using learned model weights and TF-IDF values. Display these contributions through a character-level heatmap.

07

Historical Evidence Cross-Referencing

Search the annotated linguistic corpus to identify documented donor languages, intermediate borrowing stages, spelling adaptations, and historical references.

08

Evaluation and Visualization

Evaluate the model using accuracy, Macro F1-Score, Top-K accuracy, and confusion matrices. Visualize prediction probabilities, character influences, and historical migration pathways.

09

Interactive Loanword Exploration

Integrate the trained model and historical corpus into a website where users can explore word origins, compare language pairs, and investigate linguistic migration patterns.
